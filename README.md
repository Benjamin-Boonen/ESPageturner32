# ESPageturner32
An ESP-32 based pageturner for digital sheetmusic (cause the real ones are 10x of the price of an esp)

The code is a (lightly) modified version of ESP32-BLE-Keyboard (https://github.com/T-vK/ESP32-BLE-Keyboard/)
The specific pins are coded to work with the M5Stick C plus 2 but simply changing the pins should suffice.

Project under developpement, problems may still arise
